Source repository for the interactive developer hub at **[sentiogate.github.io](https://sentiogate.github.io)**.

### Features
* **Official MCP FinOps & Router Control Plane:** Showcases `@sentiogate/mcp` (`npx -y @sentiogate/mcp`), Streamable HTTP endpoint `https://api.sentiogate.dev/v1/mcp`, and Official MCP Registry entry `io.github.SentioGate/sentiogate-mcp`.
* **Senti Bot & Coding Dashboard on Hermes Harness:** Connects to `https://sentiogate.cloud` alongside regional developer & FinOps hubs (`.dev`, `.xyz`, `.com`).
* **Zero build step needed:** Native single-file HTML5/Tailwind/CSS with interactive routing simulator.
* **Canonical link:** points to `https://sentiogate.app`.
