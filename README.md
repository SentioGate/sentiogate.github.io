# SentioGate Developer Outreach Hub (GitHub Pages)

[![GitHub Pages Deployment](https://img.shields.io/badge/Status-Active-emerald?style=flat-square)](https://sentiogate.github.io)
[![SentioGate App](https://img.shields.io/badge/SentioGate-Production_Gateway-2563eb?style=flat-square)](https://sentiogate.app)

Source repository for the interactive developer hub at **[sentiogate.github.io](https://sentiogate.github.io)**.

### Features
* **Zero build step needed:** Native single-file HTML5/Tailwind/CSS with interactive simulator.
* **Automatic GitHub Pages Hosting:** Push this repo directly to `SentioGate/sentiogate.github.io` with GitHub Pages configured to deploy from branch `main` root `/`.
* **High authority backlink network:** Fully linked with canonical tags to `https://sentiogate.app`.
